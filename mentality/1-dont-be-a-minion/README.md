# 1. Don't be a minion

Picture a recruiter's screen: hundreds of candidates for one role. Same "Aspiring Data Analyst | SQL · Python · Power BI" headline. Same Titanic notebook, same Netflix dashboard, same portfolio template with a different name on it. Same "I am a passionate, detail-oriented team player". I call these **minion profiles**. Nothing in them is wrong. They're just interchangeable, and interchangeable people don't get picked.

**If you do what everyone else does, you will not get hired.**

Best practices only get you to the starting line, the same place as every other candidate. Following every tip from every LinkedIn influencer makes you *more* like the pile, not less. What gets you the interview is the thing nobody else in the pile has.

Run two tests on everything you put out there:

- **The copy-paste test:** could 1,000 other candidates paste this line, project or page unchanged? If yes, it isn't doing anything for you.
- **The only-me test:** what is true about you that isn't true about them? A number you produced. A tool people actually use. A community you run. Data nobody else collected. An unusual path. An obsession.

If you can't answer the only-me test yet, don't polish your profile. **Go build or do one thing worth talking about**, then come back.

## Be different where it counts

Being different isn't the same as being weird. Some things should look familiar, because familiarity makes you easy to read: a clean single-column resume, a professional photo, standard section names. Be different in **substance**: the projects you build, the problems you solve, the numbers you produce, the way you write about your work. A neon resume template with skill bars isn't differentiation. A dataset you scraped yourself is.

## Why most people stay minions

Because it feels safe. If you copy the template everyone uses, nobody can say you did it wrong. But "nobody can say you did it wrong" and "somebody wants to hire you" are very different things. Blending in is a choice made out of fear, and recruiters can tell.
