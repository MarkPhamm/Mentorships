# Mentorships

Guidelines I share with my mentees. Each topic lives in its own folder, so start with whichever one you need right now.

## The one rule: don't be a minion

Recruiters scroll past hundreds of profiles that look exactly the same: *"Aspiring Data Analyst | SQL · Python · Power BI"*, a Titanic notebook, a Netflix dashboard, a portfolio that's still the template demo with a different name on it. I call these **minion profiles**. They're not wrong; they're just invisible.

**If you do what everyone else does, you will not get hired.** Following best practices only gets you to the starting line, the same place as every other candidate. What gets you the interview is the thing nobody else in the pile has.

So every guide here comes back to two questions:

1. **The copy-paste test:** could 1,000 other candidates paste this line, project or page unchanged? If yes, rewrite it.
2. **The only-me test:** what is true about *you* that isn't true about them? A number you produced, a thing you built that people use, a community you run, data nobody else collected, an obsession, an unusual path. Find it, then put it everywhere.

## How to use these guides

1. Read the guide end to end once.
2. Make the changes on your own profile, resume or project.
3. Use the checklist at the bottom of the guide to self-review, including the copy-paste test on every line.
4. Send it to me for review only after the checklist passes. We'll spend our session on the hard parts, not typos.
